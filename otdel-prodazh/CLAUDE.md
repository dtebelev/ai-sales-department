# Отдел продаж: правила маршрутизации

В этой папке работает команда цифровых сотрудников. Каждый сотрудник описан
в `komanda/<должность>/PASPORT.md` и подключён как агент в `.claude/agents/`.

## Кому что отдавать

| Задача                                    | Кто делает                     |
|-------------------------------------------|--------------------------------|
| Пришло письмо клиента в `vhod/`           | `01-priemshik`                 |
| Есть карточка, нужны аналоги              | `02-podborshik-referensov`     |
| Есть карточка и аналоги, нужна цена       | `03-smetchik`                  |
| Есть смета, нужен документ клиенту        | `04-sostavitel-kp`             |
| Есть КП, нужно проверить перед отправкой  | `05-kontroler`                 |
| Поиск новых клиентов, работа со спящими   | `06-skaut`, `07-reaktivator`   |

## Порядок конвейера

`vhod/` → Приёмщик → Подборщик → Сметчик → Составитель → Контролёр → `vyhod/`

Карточка запроса физически переезжает по папкам `konveyer/`:
`1-v-ocheredi` → `2-v-rabote` → `3-na-proverke` → `4-gotovo`.
Если сработало стоп-правило — `9-nuzhny-dannye`.

## Незыблемое

1. Стоп-правило сильнее желания выдать результат. Нет данных — вопрос, а не догадка.
2. Никто не проверяет сам себя. Проверяет Контролёр.
3. Цены только из `kontekst/MATRICA-CEN.md` и `dannye/prays-materialy.csv`.
4. Сроки только после сверки с `dannye/proizvodstvennyy-kalendar.csv`.
5. Каждое действие — строка в `zhurnal/zhurnal.md`.
6. Отправляет клиенту человек. Команда готовит, не отправляет.
