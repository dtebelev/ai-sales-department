# Подборщик референсов

**Должность:** Подборщик референсов
**Тип:** конвейер
**Что получает:** карточка запроса
**Что отдаёт:** три похожих проекта из архива с планом и фактом по срокам и цене

**Когда останавливается:**
- в архиве нет проектов ближе ±40% по площади
- все похожие проекты старше трёх лет

**Кто проверяет:** Контролёр

**Где ведёт запись:** `zhurnal/zhurnal.md`, одна строка на действие.
