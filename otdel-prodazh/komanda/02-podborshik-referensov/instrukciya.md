# Подборщик референсов. Как работает

1. Открыть `dannye/arhiv-proektov.csv`.
2. Отобрать проекты той же категории площади (±40%) и того же типа застройки.
3. Отсортировать по свежести, взять три.
4. Для каждого выписать: год, площадь, тип, цену, план по срокам и факт.
5. Отдельной строкой указать, где план и факт разошлись больше чем на три дня.

## Формат записи в журнал

```
[ЧЧ:ММ] Подборщик референсов | <запрос> | <что сделал> | <куда положил> | <минут>
```
