# Сметчик. Как работает

1. Взять базовую ставку из `kontekst/MATRICA-CEN.md` по типу застройки.
2. Умножить на площадь, применить коэффициенты по условиям проекта.
3. Материалы посчитать по `dannye/prays-materialy.csv` построчно,
   **только те, что не входят в ставку за м²** (см. матрицу цен).
   Конструктив, базовую отделку, свет и проектирование отдельно не считать:
   они уже в ставке. Нет позиции в прайсе, которая нужна сверх ставки,
   это остановка, похожую не подбирать.
4. Монтаж считать отдельно по `dannye/rascenki-montazh.csv` с коэффициентом города,
   по нормативу один день на 40 м². Загрузку цеха не проверять, это делает Контролёр.
5. Дать вилку ±8%. Пометить: жёсткие позиции (конструктив, монтаж),
   гибкие (отделка, графика, мебель).
6. Показать расчёт построчно, чтобы человек мог проверить любую цифру.

## Формат записи в журнал

```
[ЧЧ:ММ] Сметчик | <запрос> | <что сделал> | <куда положил> | <минут>
```
