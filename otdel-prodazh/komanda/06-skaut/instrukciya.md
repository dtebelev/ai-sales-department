# Скаут. Как работает

1. Раз в неделю проходить по календарю выставок.
2. Выписывать экспонентов, подходящих по профилю и размеру.
3. Отмечать, кто уже был нашим клиентом (сверка с архивом).
4. Отдавать список менеджеру с пометкой «холодный / повторный».

## Формат записи в журнал

```
[ЧЧ:ММ] Скаут | <запрос> | <что сделал> | <куда положил> | <минут>
```
