# Реактиватор

**Должность:** Реактиватор
**Тип:** по расписанию
**Что получает:** архив проектов и переписок
**Что отдаёт:** список клиентов, которым пора написать, с поводом

**Когда останавливается:**
- нет контакта в архиве

**Кто проверяет:** менеджер проектов

**Где ведёт запись:** `zhurnal/zhurnal.md`, одна строка на действие.
